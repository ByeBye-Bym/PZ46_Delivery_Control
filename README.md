## Запуск

1. Установите Node.js 20 или новее.
2. Откройте папку репозитория в VS Code.
3. В терминале запустите `npm start` или `npm.cmd start `(зависимости устанавливать не требуется).
4. Откройте `http://localhost:3046` в браузере.
5. Исследуйте запросы во вкладке **DevTools → Network → Fetch/XHR**.

Не открывайте `index.html` через `file://` и не запускайте Live Server: HTTP API обслуживает `server.js`.

## API

- `GET /api/parcels?mode=ok` → 200, массив доставок.
- `mode=http500` → HTTP 503 с объектом ошибки.
- `mode=invalid` → 200 и повреждённый JSON.
- `mode=slow` → ответ с задержкой 4500 мс.
- `mode=empty` → пустой массив.

## Проверка

Обработаны 200/503/некорректный JSON/медленный ответ/ручная отмена; тайм-аут 2500 мс; предыдущие запросы не заменяют новые данные.
